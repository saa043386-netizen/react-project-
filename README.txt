NOVA Smart Board - React/Vite

التشغيل:
1) افتحي Terminal داخل مجلد المشروع.
2) اكتبي:
   npm install
3) ثم:
   npm run dev

المشروع تجريبي للتعلم، ولا يوجد فيه دفع حقيقي.

- State / useState
- Events
- map / filter / reduce
- بحث وتصنيف
- Smart Board
- حساب الإجمالي
- localStorage
- Responsive CSS
- صفحات داخل App باستخدام state
